# 附加預期的菲利浦曲線、自然失業率與通膨動態

## 1. 核心定義：從勞動市場到通膨動態

當經濟體處於**短期（$P \neq P^e, u_t \neq u_n$）**時，勞動市場的工資設定（$W = P^e(1 - \alpha u + z)$）與價格設定（$P = (1+m)W$）結合起來，直接決定了**通貨膨脹率（$\pi_t$）與失業率（$u_t$）之間的動態關係**——即**附加預期的菲利浦曲線（Expectations-Augmented Phillips Curve）**：

$$\pi_t = \pi_t^e + (m + z) - \alpha u_t$$

將自然失業率 $u_n = \frac{m + z}{\alpha}$（使 $\pi_t = \pi_t^e$ 的失業率，又稱 **NAIRU：非加速通膨失業率**）代入，即可化簡為現代總體經濟學最核心的通膨方程式：

$$\pi_t - \pi_t^e = -\alpha(u_t - u_n)$$

> [!WARNING] Gate 1 算式不等號勘誤提醒 (`Chap-8.pdf` p.21)
> 原始教材投影片第 21 頁曾將 $u_t < u_n$ 的結果誤印為 $\pi_t < \pi_{t-1}$。經 Gate 1 驗算與課堂手寫修正：
> - 當 **$u_t < u_n$**（實際失業率低於自然失業率，勞動市場過熱）：$\pi_t > \pi_t^e$（若 $\pi_t^e = \pi_{t-1}$，則 **$\pi_t > \pi_{t-1}$，通膨加速上升**）。
> - 當 **$u_t > u_n$**（實際失業率高於自然失業率，勞動市場冷卻）：$\pi_t < \pi_t^e$（通膨減速下降）。

## 2. 菲利浦曲線的三次歷史變異（The Mutations of the Phillips Curve）

為什麼 1960 年代完美的「失業率 vs. 通膨率」抵換關係會在 1970 年代突然消失，卻又在 1990 年代末期重現？關鍵在於人們的**通膨預期形成機制**：

$$\pi_t^e = (1 - \theta)\bar{\pi} + \theta \pi_{t-1}$$

| 時期 | 預期狀態 ($\theta$) | 菲利浦曲線方程式 | 實證表現與政策教訓 |
| :--- | :---: | :--- | :--- |
| **1960 年代**<br>（早期菲利浦曲線） | **$\theta = 0$**<br>（預期錨定於 $\bar{\pi} \approx 0\%$） | $$\pi_t = (m + z) - \alpha u_t$$ | 1960 年代前通膨有正有負、平均接近 $0\%$。低失業率對應高通膨「水準」，政府誤以為能用一點通膨永久買到低失業。 |
| **1970–1995 年**<br>（加速型菲利浦曲線） | **$\theta = 1$**<br>（預期脫錨，$\pi_t^e = \pi_{t-1}$） | $$\pi_t - \pi_{t-1} = -\alpha(u_t - u_n)$$<br>（美實證：$\Delta \pi_t = 7.4\% - 1.2 u_t$） | 石油危機與持續高通膨讓大眾學聰明，改以「去年通膨」預測今年通膨。若想把失業率壓在 $u_n$（約 $6.2\%$）以下，通膨不是維持高檔，而是**每年不斷往上飆升**！ |
| **1996 年至今**<br>（通膨目標再錨定） | **$\theta = 0$**<br>（央行信譽錨定於 $\bar{\pi} = 2\%$） | $$\pi_t = 2\% - \alpha(u_t - u_n)$$<br>（美實證：$\pi_t = 2.8\% - 0.16 u_t$） | 聯準會成功建立 $2\%$ 通膨目標信譽，大眾不再隨短期油價波動改動預期，曲線重回「失業與通膨水準」關係，且斜率變得極為平坦（$\alpha = 0.16, u_n \approx 5.0\%$）。 |

## 3. 自然失業率為何並非一成不變？

自然失業率 $u_n = \frac{m + z}{\alpha}$ 完全由勞動市場結構決定：
- **跨國差異（歐洲 vs. 美國）**：部分歐洲國家因較高額的失業救濟與較嚴格的資遣限制（高 $z$）及較高產品市場管制（高 $m$），自然失業率長期高於美國。
- **美國 $u_n$ 自 1980 年代（6%–7%）降至 2018 年（4%–5%）的四大原因（`[[source-blanchard-chap-8]]`）**：
  1. **全球化與外國競爭**：壓縮企業定價加成 $m$ 與工會議價力 $z$。
  2. **臨時派遣業（Temp Agencies）與網路求職普及**：降低摩擦性媒合時間。
  3. **人口高齡化**：年輕人（16–24 歲）最常換工作、失業率最高；嬰兒潮世代步入中年使年輕勞工佔比自 $24\%$ 降至 $13\%$。
  4. **監禁率與失能保險請領人數上升**。

## 4. 三大進階陷阱：工資指數化、名目工資僵固性與盧卡斯批判

### 4.1 工資指數化（Wage Indexation, $\lambda$）的通膨放大器
若經濟體中有比例 $\lambda$ 的勞工薪資會隨「當期實際通膨 $\pi_t$」自動調漲，菲利浦曲線變為：
$$\pi_t - \pi_{t-1} = -\frac{\alpha}{1 - \lambda}(u_t - u_n)$$
當 $\lambda$ 接近 $1$ 時，乘數 $\frac{1}{1-\lambda}$ 趨近無限大——只要失業率稍微低於 $u_n$，工資與物價就會在同一年內無數次互相追逐，瞬間引爆**惡性通膨（Hyperinflation）**！

### 4.2 通縮與名目工資向下僵固性（Downward Nominal Wage Rigidity）
為什麼 1930 年代大蕭條失業率高達 $25\%$，物價卻沒有無止境暴跌？
- **人性心理（貨幣幻覺與減薪抗拒）**：勞工可以接受「通膨 $4\%$、老闆只加薪 $2\%$」（實質減薪 $2\%$），但若「通膨 $0\%$、老闆直接把帳面薪水扣 $2\%$」，勞工會強烈反抗、士氣崩潰！
- 因此，當通膨接近 $0\%$ 或陷入通縮時，名目工資無法順利下調，菲利浦曲線在低通膨區間會變得極為平坦甚至失效。

### 4.3 反通膨（Disinflation）的代價：盧卡斯批判 vs. 沃克反通膨實證
當 1979 年美國通膨高達 $13.3\%$ 時，把通膨壓下來一定要經歷痛苦的高失業嗎？
- **盧卡斯批判（Lucas Critique, Robert Lucas & Thomas Sargent）**：認為只要央行展現絕對堅定的反通膨信譽（Credibility），勞資雙方會立刻把預期通膨 $\pi_t^e$ 下調，無須付出高失業代價（無痛反通膨）。
- **1979–1985 年 Paul Volcker 歷史實證**：儘管聯準會主席 Volcker 將利率拉高至 $15\%$，但因勞動契約分批簽訂（Staggered Wage Contracts）且市場起初半信半疑，美國最終仍付出了 **1982 年失業率飆至 $10.8\%$、累計超額失業達 $12.7$ 個百分點年** 的慘痛代價，才換來往後三十年的低通膨與高信譽。
