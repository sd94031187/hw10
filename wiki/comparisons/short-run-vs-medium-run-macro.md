# 總體經濟的短期與中期大對決：需求驅動 vs. 供給約束與政策效果差異

在學習 Blanchard 總體經濟學時，從第 3～6 章（短期 `IS-LM`）跨入第 7～9 章（中期 `WS-PS` 與 `IS-LM-PC`）最核心的思維轉換，就是搞懂**「為什麼在短期很有效的印鈔降息與政府撒錢，到了中期卻無法提高總產出？」**

本頁系統性對比**短期（Short Run，1～2 年）**與**中期（Medium Run，3～10 年）**的核心假設、均衡決定機制與財政/貨幣政策效果。

---

## 1. 核心架構與假設對比：短期 vs. 中期

| 比較維度 | 短期（Short Run：約 1～2 年內） | 中期（Medium Run：約 3～10 年） |
| :--- | :--- | :--- |
| **對應教材與模型** | Ch.3～Ch.6：`IS-LM` 模型<br>（商品市場 + 金融市場） | Ch.7～Ch.9：`WS-PS` + `IS-LM-PC` 模型<br>（加入勞動市場與菲利浦曲線） |
| **物價與名目工資行為** | **價格與工資僵固（Sticky Prices & Wages）**<br>（實證顯示貨幣政策衝擊後前 6 季物價幾乎不動，`[[source-blanchard-chap-5]]` Slide 54） | **物價與工資充分調整（Flexible Prices & Wages）**<br>勞資雙方重新談判工資、廠商重新調整售價，預期物價等於實際物價（$P^e = P, \pi = \pi^e$）。 |
| **什麼決定總產出（$Y$）？** | **總需求（Aggregate Demand）主導**：<br>消費者、企業與政府想買多少，廠商就生產多少（$Y = C + I + G$）。 | **總供給與勞動市場結構（Supply Side）主導**：<br>產出必定回歸由技術、人口與制度（$m, z$）決定的**潛在產出（自然產出 $Y_n$）**。 |
| **失業率（$u$）與通膨（$\pi$）** | 失業率隨總需求波動（可高於或低於 $u_n$）；通膨尚未充分反應。 | 失業率必定回歸**自然失業率（$u = u_n = \frac{m+z}{\alpha}$）**；通膨穩定於央行目標 $\bar{\pi}$（或由貨幣成長率決定）。 |
| **實質利率（$r$）由誰決定？** | 由**中央銀行貨幣政策**直接決定（$r = \bar{r}$）。 | 必須收斂至使總需求等於潛在產出 $Y_n$ 的**自然實質利率（$r_n$）**。 |
| **生活化比喻** | **餐廳短期爆單**：菜單價格還沒改，客人點越多，廚房就加班做越多（需求決定產量）。 | **餐廳中長期調整**：員工累了要求加薪、老闆發現成本大漲於是重印菜單漲價，客流量回到餐廳正常負荷上限（產能與成本決定產量）。 |

## 2. 兩大政策在「短期 vs. 中期」的完全不同結局

為什麼政治人物喜歡在選舉前要求央行降息或擴大財政支出？因為**短期看得見繁榮，中期才會浮現通膨或排擠代價**！

### 2.1 貨幣政策（央行降息 / 印鈔擴張）的短中期對比

| 觀察指標 | 短期效果（1～2 年內） | 中期最終結局（3～10 年後） |
| :--- | :--- | :--- |
| **實質利率（$r$）** | **下降**（央行調降政策利率 $r < r_n$） | **打回原形**（為壓抑通膨，央行被迫把實質利率升回自然利率 **$r = r_n$**） |
| **實質產出（$Y$）與失業（$u$）** | **產出增加（$Y > Y_n$）、失業率下降（$u < u_n$）**<br>（便宜資金刺激企業投資與消費） | **完全不變（$Y = Y_n, u = u_n$）！**<br>（這就是著名的**「中期貨幣中立性 Neutrality of Money」**） |
| **物價與通膨率（$\pi$）** | 初期幾乎不變或微幅上升 | **通膨率與名目利率永久上升（$\pi = g_M, i = r_n + g_M$）** |
| **核心啟示** | 貨幣政策是強效的「短期景氣退燒/強心針」。 | 在中期，亂印鈔票買不到任何一點額外的真實 GDP 或就業，100% 變成通貨膨脹！ |

### 2.2 財政政策（政府縮減赤字：減支 $G \downarrow$ 或加稅 $T \uparrow$）的短中期對比

| 觀察指標 | 短期效果（若央行未即時降息） | 中期最終結局（央行調整利率收斂後） |
| :--- | :--- | :--- |
| **總產出（$Y$）** | **產出萎縮（$Y < Y_n$）**，引發短期衰退與失業上升 | **總產出回到潛在產出（$Y = Y_n$）**，總量不變！ |
| **實質利率（$r$）** | 維持原水準 $r_n$ | 因通膨下滑，央行將實質利率調降至**更低的新自然利率（$r_n' < r_n$）** |
| **私人投資（$I$）與產出結構** | 投資因產出萎縮而減少 | 因利率降至 $r_n'$，**私人企業投資大幅增加（$I \uparrow$）**，1 對 1 填補政府減支 $G \downarrow$ 的缺口！ |
| **核心啟示** | 財政緊縮在短期會帶來陣痛（需求減少）。 | 在中期不會改變總產出 $Y_n$，但會**改變 GDP 的組成結構**（把資源從政府部門 $G$ 釋放給私人企業投資 $I$，有利於長期資本累積）。 |

## 3. 需求衝擊 vs. 供給衝擊在短中期的影響（為何石油危機最難救？）

- **負向需求衝擊（如股市下跌、消費信心崩潰）**：
  - 短期產出下跌（$Y < Y_n$）、通膨降溫（$\pi \downarrow$），但**中期潛在產出 $Y_n$ 並未受損**。只要央行及時降息（且未卡在零利率下限），就能無痛把產出拉回 $Y_n$，同時穩定通膨（神聖巧合 Divine Coincidence）。
- **負向供給衝擊（如 1970 年代石油危機，油價暴漲推升企業加成 $m \uparrow$）**：
  - 直接打擊供給面，使**中期自然失業率上升（$u_n \uparrow$）、潛在產出天花板永久下移（$Y_n \to Y_n' < Y_n$）**！
  - 此時會爆發**「停滯性通膨（Stagflation）」**：經濟一邊邁向更低的產出 $Y_n'$（衰退），一邊卻因為實際產出高於縮小後的潛在產能而狂冒通膨（$\pi \uparrow$），讓央行陷入「升息會加重衰退、降息會引爆通膨」的兩難。
